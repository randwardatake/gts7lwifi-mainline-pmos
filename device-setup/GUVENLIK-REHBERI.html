📺 YouTube nasıl akıcı olur

Bu tablette Adreno GPU video çözmez; Venus donanım çözücüsüne de tarayıcı erişemiyor. Bu yüzden hedef: CPU'nun yükünü azaltmak.

1) h264ify (kuruldu)

YouTube'u ağır VP9/AV1 yerine hafif H.264'e zorlar. Chromium'da otomatik yüklenir. İkonuna tıklayıp "Block 60fps" ve maksimum 720p seçeneklerini açman şiddetle önerilir.

2) Kalite

Kontrol için: video → dişli → 720p. Doğrulama: videoya sağ tık → "Stats for nerds" → codecs satırında avc1 (H.264) görmelisin (vp09 değil).

3) En akıcı yol (opsiyonel — istersen sonra kurarız)

Gerçekten akıcı 1080p için Venus donanım çözücüsünü mpv/FreeTube kullanabilir (cihazda mpv zaten v4l2m2m destekliyor). Tek komutla:

sudo apk add mpv yt-dlp
mpv --hwdec=v4l2m2m-copy "https://youtu.be/VIDEO_ID"     # donanim hizlandirmali
# veya FreeTube:  sudo apk add freetube

Şimdilik "sadece tarayıcı" dedin; fikrin değişirse bu yol hazır.

Performans Modu (kısayol eklendi)

Masaüstünde "Performans Modu" → AÇ: CPU governor performance + GPU performance (klokları sabitler). KAPA: schedutil (varsayılan, pil dostu). Terminalden de:

perfmode.sh on      # performans (sicaklik/pil artar)
perfmode.sh off     # varsayilan (pil dostu)
perfmode.sh status  # anlik klok + sicaklik

Benchmark sonucu (bu cihazda ölçüldü)

ModCPU (sysbench olay/sn)Maks. sıcaklıkPrime klok
schedutil (varsayılan)558761 °Cihtiyaçta 3.09 GHz

Yorum: Tam yük altında schedutil zaten tüm çekirdekleri maks. hıza çıkarıyor — bu yüzden CPU skoru eşit (fark gürültü seviyesinde), ama performans modu daha sıcak. Performans modunun asıl faydası: GPU'yu 670 MHz'de sabit tutmak (oyunlarda kare tutarlılığı) ve ani/gecikmeye duyarlı işlerde ramp gecikmesini yok etmek.

➜ Öneri: Günlük kullanımda KAPALI bırak (pil + serinlik). Oyun/emülasyon öncesi AÇ.

🧰 Güvenlik araçları (kuruldu)

Hepsi dahili donanımla, kernel'e dokunmadan çalışır. Masaüstünde kısayolları var.

Ağ keşif / tarama

nmap -sn 192.168.1.0/24              # canli host tara (ping sweep)
sudo nmap -sS -sV 192.168.1.10       # port + servis surumu
sudo arp-scan --localnet             # yerel agdaki cihazlar (MAC)
sudo masscan 192.168.1.0/24 -p1-1000 --rate 1000

Trafik analizi

sudo tcpdump -i wlan0 -n port 80 or port 443
sudo tshark -i wlan0 -Y "http.request"     # terminalde
wireshark                                   # GUI (masaustu kisayolu)

⚠ Wireshark ile root'suz yakalama için: bir kez çıkış yapıp tekrar giriş yap (wireshark grubu üyeliğin aktifleşsin). İzinler zaten ayarlandı (dumpcap cap_net_raw).

LAN MITM — bettercap / ettercap

sudo bettercap -iface wlan0
  » net.probe on            # agdaki cihazlari bul
  » set arp.spoof.targets 192.168.1.10
  » arp.spoof on; net.sniff on
sudo ettercap -T -i wlan0 -M arp /// ///   # metin modu ARP MITM

Bluetooth / BLE

bluetoothctl                     # scan on   → cevredeki cihazlar
sudo hcitool lescan              # BLE tarama
sudo bettercap -eval "ble.recon on; sleep 20; ble.show"

WiFi izleme (pasif)

wavemon                          # sinyal/kanal (GUI-benzeri, terminal)
iw dev wlan0 scan | grep SSID    # cevredeki aglar

Şifre / hash (offline)

hashcat -I                       # cihaz/backend testi
hashcat -m 22000 handshake.hc22000 wordlist.txt   # WPA (yakalanmis handshake)
john --wordlist=rockyou.txt hashes.txt
hydra -l admin -P wordlist.txt 192.168.1.1 ssh    # SADECE kendi cihazinda

Yardımcı

sudo macchanger -r wlan0         # rastgele MAC (once: ip link set wlan0 down)
sudo nft list ruleset            # guvenlik duvari kurallari

Gerçek deauth istersen (gelecekte)

Enjeksiyon destekli bir harici USB WiFi adaptörü + kernel'e sürücü eklemek gerekir:

  • Atheros AR9271 (ath9k_htc) — enjeksiyonda altın standart, tam mainline. Önerilen.
  • MediaTek MT7612U (mt76x2u) veya Realtek RTL8812AU.

Bu kernel'de bu sürücüler kapalı (CONFIG_ATH9K_HTC vb. set değil). Adaptörü alırsan kernel'i yeniden derleyip (pmbootstrap ile) bu sürücüleri + aircrack-ng, mdk4, hcxdumptool'u ekleriz. O zaman deauth/handshake/PMKID tam çalışır.

Not: Kernel yeniden derleme + flash mevcut çalışan sisteme küçük risk taşır; o yüzden şimdilik yapmadık.

↩ Geri alma (bir şey ters giderse)

# Ekran yirtilma ayarini geri al:
xfconf-query -c xfwm4 -p /general/vblank_mode -s xpresent && xfwm4 --replace &

# Chromium ayarlarini geri al:
sudo cp /etc/chromium/chromium.conf.bak /etc/chromium/chromium.conf
sudo rm /etc/chromium/policies/managed/h264ify.json

# Guvenlik araclarini kaldir:
sudo apk del nmap arp-scan masscan wavemon wireshark tshark tcpdump \
  bettercap ettercap bluez bluez-deprecated hashcat john hydra macchanger

# Performans modu her zaman KAPA:
perfmode.sh off

Kernel/boot hiç değiştirilmedi — sistem bozulma riski yok.
